# Data Analyzer and Transformer Program 📊

A Python application designed to analyze numerical datasets and perform mathematical transformations such as factorial calculations and statistical analysis.

---

## 📌 Features

- **Factorial Calculation:** Calculates the factorial of a given number using recursion.
- **Dataset Statistics:** Computes key statistical values (Minimum, Maximum, Sum, and Average) from a list of numbers.
- **Data Transformation:** Tools for processing and transforming data effectively.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Concepts Used:** Functions, Recursion, Data Processing (Lists/Tuples)
